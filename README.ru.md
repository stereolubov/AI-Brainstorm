# AI Brainstorm

Десктопное приложение для группового брейншторма сразу с несколькими
AI-моделями через OpenRouter, Requesty или свой собственный
OpenAI-совместимый сервер (локальный или self-hosted). Claude, ChatGPT,
Grok, Gemini и MistralAI спорят, развивают и дополняют идеи друг друга —
под управлением ведущего (ИИ или вас самих) — а вы наблюдаете,
подключаетесь или направляете обсуждение.

Чистый Python + стандартная библиотека (`tkinter`, `urllib`, `json`,
`threading`, `re`, `logging`) — никакой `pip install` для запуска не нужен.

English version: [README.md](README.md)

## Провайдеры API

Выбираются из выпадающего списка прямо над полем API-ключа в
настройках — каждый профиль запоминает свой выбор, ключ и (для Custom)
URL.

- **OpenRouter** (по умолчанию) — самый полный вариант: семейства
  моделей, фильтр бесплатных, проверка баланса, веб-поиск ведущего и
  отслеживание стоимости в $ — всё работает.
- **Requesty** — похожий по устройству хостед-роутер (та же конвенция
  ID `провайдер/модель`, поэтому семейства работают так же, и он тоже
  отдаёт стоимость запроса, поэтому бюджет тоже работает). Нет фильтра
  бесплатных (в его списке моделей нет цен), нет кнопки проверки
  баланса, нет веб-поиска ведущего — точные причины, почему каждая из
  этих фич не встроена «на скорую руку», смотрите в `providers.py`.
- **Custom** — любой другой OpenAI-совместимый сервер: локальный (LM
  Studio, Ollama и т.д.), self-hosted прокси, или другой облачный
  провайдер. URL вписывается прямо в настройках. Нет семейств (у
  произвольного сервера нет фиксированной конвенции имён вендоров),
  нет баланса/фильтра бесплатных/веб-поиска, нет отслеживания бюджета
  в $ (такие серверы практически никогда не отдают стоимость) — только
  чат плюс необязательный сырой JSON-фрагмент рассуждений на каждого
  участника, см. ниже. **Экспериментально** — форматы запроса/ответа
  достаточно различаются между локальными серверами, так что
  какие-то шероховатости ожидаемы; про рекомендованное время ответа
  локальных моделей — в разделе «Известные проблемы» ниже.

## Запуск

Нужен Python 3.9+ (на Windows tkinter идёт в комплекте стандартного
установщика с python.org — просто не снимайте галочку `tcl/tk` при установке).

```
python main.py
```

## Сборка в один exe-файл (Windows)

```
pip install pyinstaller
pyinstaller --onefile --windowed --icon=favicon.ico --add-data "favicon.ico;." --name AIBrainstorm main.py
```

Положите `favicon.ico` рядом с `main.py` перед сборкой, если хотите
свою иконку — `--icon` встраивает её в сам exe-файл (то, что видно в
Проводнике), а `--add-data` кладёт сам файл внутрь, чтобы приложение в
рантайме могло установить иконку окна/таскбара через `iconbitmap()` и
напрямую через WinAPI (`WM_SETICON`) — для чёткой иконки в Alt+Tab и
списках переходов, а не размытого апскейла. Уберите оба флага, если
иконки нет.

Если пересобираете с другой иконкой поверх уже существующей сборки —
сначала удалите `build/`, `dist/` и файл `.spec`, PyInstaller активно кэширует.

Готовый файл появится в `dist/AIBrainstorm.exe`. Уберите `--windowed`
при отладке, чтобы видеть вывод консоли.

## Язык интерфейса

Интерфейс, промпты, которые приложение отправляет моделям (персонажи,
инструкции ведущему), и технический лог — переводятся вместе. Доступные
языки — обычные JSON-файлы в `~/.ai_brainstorm/locales/`:

```
{"code": "ru", "name": "Русский", "translations": {"key": "текст", ...}}
```

`Russian.json` и `English.json` создаются автоматически при первом
запуске и самовосстанавливаются, если их удалить или они повредятся.
Добавьте свой файл с любым `code`/`name` (например, `French.json`),
чтобы получить новый язык — папка пересканируется при каждом запуске,
правки кода не нужны. Если сохранённый язык не найден (например,
кастомный файл удалили), приложение тихо откатывается на английский и
запоминает это.

Переключение языка — через выпадающий список на вкладке «Настройки»,
применяется сразу, интерфейс перестраивается на месте.

## Тема

Светлая и Тёмная, переключаются выпадающим списком прямо рядом с
выбором языка на вкладке «Настройки». Применяется сразу, без
перезапуска. Как и язык — это общеприложенческая настройка, хранится в
`~/.ai_brainstorm/active_profile.json`, не зависит от того, какой
профиль активен. Акцентные цвета участников (терракотовый Claude,
красный для ошибок и т.д.) специально одинаковы в обеих темах — это
цвета бренда, а не «хром» интерфейса.

## Профили

Настройки хранятся в именованных профилях — каждый самостоятельный
JSON-файл со своим API-ключом:

- Windows: `C:\Users\<имя>\.ai_brainstorm\profiles\<имя>.json`
- Linux/macOS: `~/.ai_brainstorm/profiles/<имя>.json`

Удобно для нескольких аккаунтов/провайдеров или разных наборов
участников под разные случаи. Выпадающий список на вкладке «Настройки»
применяет профиль сразу при выборе — отдельного шага «загрузить» нет.
«Сохранить как…» сохраняет текущую форму под новым именем, не трогая
файл старого активного профиля. «Открыть папку настроек» открывает
`~/.ai_brainstorm/` прямо в системном файловом менеджере.

Имя активного профиля, язык интерфейса и видимость вкладки «Лог» —
общеприложенческие настройки, хранятся отдельно от содержимого профиля
(в `~/.ai_brainstorm/active_profile.json`) — не меняются при
переключении профилей.

## Участники

**Стандартные семейства** (до 5, только OpenRouter/Requesty) — Claude,
ChatGPT, Grok, Gemini, MistralAI. Каждое семейство сверяется с живым
списком моделей провайдера через regex (у обоих одинаковая конвенция
`вендор/модель`), поэтому выпадающий список конкретных моделей сам
актуализируется по мере выхода новых — жмите «Обновить список моделей»
когда угодно. Выбирайте конкретную модель внутри семейства, правьте
персонажа, задавайте уровень рассуждений (см. ниже). Недоступно для
Custom — у произвольного сервера нет фиксированной конвенции имён
вендоров, сверяться не с чем.

**Свои модели** (до 3 вместе с семействами, либо все 8 в плоском
режиме — для Custom это единственный вариант, см. ниже) — любая другая
модель по точному ID, со своим названием, персонажем и настройкой
рассуждений. Поле ID автодополняется из обновлённого списка моделей,
если провайдер его вообще отдаёт. Один и тот же ID модели можно
намеренно указать в нескольких слотах — удобно дать одной модели
несколько разных персонажей (например, две копии одной локальной
модели — одна ироничная, другая серьёзная); каждая всё равно считается
полноценным отдельным участником — со своим местом в очереди и своим
отслеживанием «кто говорил последним». А вот дублировать модель, уже
занятую выбранным семейством, свой слот по-прежнему не может — у
семейств отдельный, собственный контекст уникальности.

От 2 до 8 участников одновременно. В чате у каждого в подписи видна
конкретная используемая модель, например «Claude (claude-sonnet-5)».

**Полный отказ от семейств** — галочка «Использовать семейства» в
блоке стандартных моделей (скрыта для Custom, где принудительно
выключена); снимите её, чтобы превратить раскладку «5 стандартных + 3
своих» в **8 полностью общих плоских слотов** (без предустановленных
персонажей и фирменных цветов вендоров). При снятии галочки текущая
конфигурация семейств переносится в освободившиеся слоты в
фиксированном порядке Claude → ChatGPT → Grok → Gemini → MistralAI,
независимо от того, какие были отмечены — так визуальный порядок
остаётся предсказуемым; ваши прежние 3 своих слота при этом не
трогаются и не сдвигаются. При обратном включении конфигурация
семейств восстанавливается как была — оба набора всегда хранятся в
профиле одновременно, независимо от того, какой сейчас активен.

**Только бесплатные модели** (только OpenRouter) — галочка, которая
фильтрует автодополнение ID до моделей с ценой $0, определяется по
полю цены прямо от OpenRouter и обновляется вместе с основным списком
моделей. Переключается мгновенно, без лишнего сетевого запроса.
Недоступно для Requesty (в их списке моделей нет цен) и Custom.

### Уровни рассуждений

Необязательный бюджет на скрытое «размышление» модели перед видимым
ответом. Для OpenRouter/Requesty — выбор одного из 4 уровней (Выключено
/ Низкий / Средний / Высокий) из выпадающего списка на каждого
участника; приложение само переводит выбор в то, что реально ждёт API
конкретного провайдера (числовой бюджет токенов для OpenRouter, слово
уровня для Requesty — подтверждено по документации каждого, не
угадано). По умолчанию выключено: для обычного брейншторма редко даёт
пользу, а счёт может незаметно вырасти. Не все модели это
поддерживают — там настройка просто не даёт эффекта.

Для **Custom** угадать формат невозможно в принципе — OpenRouter,
Requesty и LM Studio оформляют это по-разному, единого перевода не
существует. Вместо списка — у каждого участника своё текстовое поле
«Рассуждения (JSON, необязательно)»: впишите точный фрагмент, который
ждёт ваш сервер (например, `{"reasoning": {"effort": "low"}}`), он
мержится в тело запроса как есть. Пусто — ничего не отправляется.
Невалидный JSON просто пропускается с предупреждением во вкладке
«Лог», реплика при этом не падает.

## Ведущий

Вместо строгой очереди порядок реплик определяет ведущий — а также что
участнику делать, зачем, и не пора ли подводить итог.

- **ИИ-ведущий** (по умолчанию) — отдельный, обычно дешёвый, вызов
  модели после каждой реплики. Скрыт из самого чата.
- **Человек-ведущий** — вы сами выбираете каждого оратора, без
  дополнительных затрат API. Та же панель позволяет оставить
  комментарий или сразу завершить сессию.

**Участие** — если включено, ведущий может время от времени передавать
слово и вам (ограничено так, что это не может случиться два раза
подряд — предвзятый ведущий не сможет застопорить сессию на вас
бесконечно). Ваши реплики не считаются в лимите реплик и бюджете.

**Итог сессии** — необязательный дополнительный вызов после окончания
сессии, просит модель ведущего дать тезисный пересказ: ключевые идеи,
точки согласия/разногласий, общий вывод.

**Проверка интернета перед стартом** (только OpenRouter) — по
умолчанию выключено. Если включить, ведущий перед началом обсуждения
делает один веб-поиск (встроенный плагин `web` от OpenRouter,
отдельный ключ поисковика не нужен) — ищет всё относящееся к теме:
недавние события или неочевидную связь с текущей датой, которую
участники иначе могли бы полностью упустить. Находки появляются
отдельным сообщением в чате и попадают в историю обсуждения, так что
все участники видят их с первой же реплики. Добавляет небольшую
стоимость за сам поиск, показывается как обычная строка стоимости. Не
предлагается для Requesty (их веб-поиск per-модельный, не универсальный
флаг) и Custom.

**Вмешательство** — поставить обсуждение на паузу, оставить уточнение
для участников, или сразу завершить сессию. Отдельная кнопка в режиме
ИИ-ведущего; встроено в панель выбора оратора в режиме человека.

Самая последняя реплика сессии всегда направляется к подведению итога,
независимо от того, вспомнил ли об этом сам ведущий.

## Бюджет и длина

Два независимых стоп-фактора — что наступит раньше:

- **Бюджет** ($, задаётся в настройках; только OpenRouter/Requesty —
  для Custom поле скрыто целиком, он практически никогда не отдаёт
  стоимость в $) — включает и реплики участников, и вызовы ведущего.
  Провайдер возвращает точную стоимость каждого запроса; она показана
  под каждой репликой (курсивом, серым, по правому краю), с разбивкой,
  если туда же попадает стоимость вызова ведущего (например, «$0.0031
  + ведущий $0.0012 = $0.0043»).
- **Макс. реплик** (задаётся на вкладке «Чат») — считает только реплики
  участников, не вызовы самого ведущего и не ваши реплики. Единственный
  стоп-фактор, работающий для Custom.

Модель, начавшая отдавать ошибки (лимиты запросов, таймауты и т.п.),
уходит на короткое «охлаждение» и исключается из вариантов выбора
ведущего — тихо, без спама в чат; причина остаётся видна во вкладке
«Лог».

## Отображение чата

- `**жирный**`, `` `инлайн-код` ``, блоки ` ```кода``` `, заголовки и
  маркированные списки рендерятся по-настоящему, а не сырым markdown-текстом.
- Реплики визуально разделены линией.
- Собственные заметки (тема, комментарии, реплики) выделены отдельным
  цветом; итог сессии — своим акцентным цветом.
- **Ctrl+C** копирует выделенное, **Ctrl+A** выделяет всё, «Копировать
  всё» — весь лог одним кликом.
- **Экспорт…** сохраняет в `.md` или `.txt`, собирается из исходного
  текста реплик (со всей markdown-разметкой как есть), а не из того,
  что отрисовано на экране.

## Вкладка «Лог»

Необязательная вкладка, дублирующая то, что показала бы консоль —
вызовы моделей, стоимость, решения ведущего, ошибки. Включается на
вкладке «Настройки»; хранит свою историю всю сессию приложения, даже
пока скрыта. Копируется и выделяется так же, как лог чата.

## Структура проекта

```
ai_brainstorm/
├── main.py             — точка входа, интерфейс на Tkinter, логика ведущего/воркера
├── config.py            — профили, общеприложенческие настройки, пути к папке языков
├── models_catalog.py    — семейства моделей, уровни рассуждений, сборка каталога
├── api_client.py        — вызовы API вне привязки к провайдеру: чат, ведущий, список моделей, баланс ключа

├── theme.py               — палитры Светлая/Тёмная, тема для ttk.Style() и обычных Text/Canvas
├── providers.py           — реестр провайдеров (OpenRouter/Requesty/Custom) и флаги возможностей
├── favicon.ico           — иконка приложения (необязательно, добавьте свою)
├── README.md / README.ru.md
```

## Известные проблемы

- **Профили, которые уже пользовались переключением семейства↔плоские
  слоты до 30.08.2026, после обновления могут показать не те модели в
  3 «своих» слотах.** Изменился внутренний порядок хранения (семейства
  теперь всегда занимают фиксированные слоты 1-5, «свои» слоты
  переехали на 6-8 — так переключение больше не перемешивает список).
  Профили, которые ни разу не переключали этот режим, никак не
  затронуты. Если ваш профиль пострадал — откройте его `.json`-файл в
  `~/.ai_brainstorm/profiles/` и переставьте элементы массива
  `custom_models` так, чтобы 1-5 были ваши семейства (в порядке
  Claude/ChatGPT/Grok/Gemini/MistralAI), а 6-8 — ваши собственные
  модели, либо проще просто заново впишите свои слоты руками в
  настройках.
- **Самовосстановление файлов языка добавляет только отсутствующие
  ключи, не исправленные формулировки.** Если в будущем обновлении
  поправится текст уже существующего перевода, ваш сохранённый
  `Russian.json`/`English.json` в `~/.ai_brainstorm/locales/` сохранит
  прежний текст для этого ключа — самовосстановление дополняет только
  полностью отсутствующие ключи. Если после обновления какая-то
  подпись выглядит устаревшей — удалите соответствующий файл, при
  следующем запуске он пересоздастся из актуальных встроенных значений.
- **Для Custom/локальных моделей не рекомендуется использовать тяжёлые
  модели, если ответ занимает больше примерно 3 минут.** Это потолок
  таймаута запроса в приложении — для облачных провайдеров с большим
  запасом, но крупная локальная модель с рассуждениями на скромном
  железе вполне может его превысить, тогда именно эта реплика
  прерывается (модель уходит на короткое «охлаждение», сессия
  продолжается — ничего не падает, но конкретная реплика теряется).
  Если это происходит часто — выберите модель полегче/побыстрее или
  снизьте уровень рассуждений.
