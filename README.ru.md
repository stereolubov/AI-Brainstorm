# AI Brainstorm

Десктопное приложение для группового брейншторма сразу с несколькими
AI-моделями через единый API-ключ OpenRouter. Claude, ChatGPT, Grok,
Gemini и MistralAI спорят, развивают и дополняют идеи друг друга —
под управлением ведущего (ИИ или вас самих) — а вы наблюдаете,
подключаетесь или направляете обсуждение.

Чистый Python + стандартная библиотека (`tkinter`, `urllib`, `json`,
`threading`, `re`, `logging`) — никакой `pip install` для запуска не нужен.

English version: [README.md](README.md)

## Запуск

Нужен Python 3.9+ (на Windows tkinter идёт в комплекте стандартного
установщика с python.org — просто не снимайте галочку `tcl/tk` при установке).

```
python main.py
```

## Сборка в один exe-файл (Windows)

```
pip install pyinstaller
pyinstaller --onefile --windowed --icon=favicon.ico --add-data "favicon.ico;." --name AIBrainstorm main.py
```

Положите `favicon.ico` рядом с `main.py` перед сборкой, если хотите
свою иконку — `--icon` встраивает её в сам exe-файл (то, что видно в
Проводнике), а `--add-data` кладёт сам файл внутрь, чтобы приложение в
рантайме могло установить иконку окна/таскбара через `iconbitmap()` и
напрямую через WinAPI (`WM_SETICON`) — для чёткой иконки в Alt+Tab и
списках переходов, а не размытого апскейла. Уберите оба флага, если
иконки нет.

Если пересобираете с другой иконкой поверх уже существующей сборки —
сначала удалите `build/`, `dist/` и файл `.spec`, PyInstaller активно кэширует.

Готовый файл появится в `dist/AIBrainstorm.exe`. Уберите `--windowed`
при отладке, чтобы видеть вывод консоли.

## Язык интерфейса

Интерфейс, промпты, которые приложение отправляет моделям (персонажи,
инструкции ведущему), и технический лог — переводятся вместе. Доступные
языки — обычные JSON-файлы в `~/.ai_brainstorm/locales/`:

```
{"code": "ru", "name": "Русский", "translations": {"key": "текст", ...}}
```

`Russian.json` и `English.json` создаются автоматически при первом
запуске и самовосстанавливаются, если их удалить или они повредятся.
Добавьте свой файл с любым `code`/`name` (например, `French.json`),
чтобы получить новый язык — папка пересканируется при каждом запуске,
правки кода не нужны. Если сохранённый язык не найден (например,
кастомный файл удалили), приложение тихо откатывается на английский и
запоминает это.

Переключение языка — через выпадающий список на вкладке «Настройки»,
применяется сразу, интерфейс перестраивается на месте.

## Тема

Светлая и Тёмная, переключаются выпадающим списком прямо рядом с
выбором языка на вкладке «Настройки». Применяется сразу, без
перезапуска. Как и язык — это общеприложенческая настройка, хранится в
`~/.ai_brainstorm/active_profile.json`, не зависит от того, какой
профиль активен. Акцентные цвета участников (терракотовый Claude,
красный для ошибок и т.д.) специально одинаковы в обеих темах — это
цвета бренда, а не «хром» интерфейса.

## Профили

Настройки хранятся в именованных профилях — каждый самостоятельный
JSON-файл со своим API-ключом:

- Windows: `C:\Users\<имя>\.ai_brainstorm\profiles\<имя>.json`
- Linux/macOS: `~/.ai_brainstorm/profiles/<имя>.json`

Удобно для нескольких аккаунтов OpenRouter или разных наборов
участников под разные случаи. Выпадающий список на вкладке «Настройки»
применяет профиль сразу при выборе — отдельного шага «загрузить» нет.
«Сохранить как…» сохраняет текущую форму под новым именем, не трогая
файл старого активного профиля. «Открыть папку настроек» открывает
`~/.ai_brainstorm/` прямо в системном файловом менеджере.

Имя активного профиля, язык интерфейса и видимость вкладки «Лог» —
общеприложенческие настройки, хранятся отдельно от содержимого профиля
(в `~/.ai_brainstorm/active_profile.json`) — не меняются при
переключении профилей.

## Участники

**Стандартные семейства** (до 5) — Claude, ChatGPT, Grok, Gemini,
MistralAI. Каждое семейство сверяется с живым списком моделей
OpenRouter через regex, поэтому выпадающий список конкретных моделей
сам актуализируется по мере выхода новых — жмите «Обновить список
моделей» когда угодно. Выбирайте конкретную модель внутри семейства,
правьте персонажа, задавайте бюджет токенов на рассуждения (см. ниже).

**Дополнительные модели** (до 3) — любая другая модель OpenRouter по
точному ID (например, `deepseek/deepseek-v4-flash-0731`), со своим
названием, персонажем и уровнем рассуждений. Поле ID автодополняется
из того же обновлённого списка моделей.

От 2 до 8 участников одновременно. В чате у каждого в подписи видна
конкретная используемая модель, например «Claude (claude-sonnet-5)».

### Уровни рассуждений

Необязательный бюджет токенов на скрытое «размышление» модели перед
видимым ответом — Выключено / Низкий (≤1024) / Средний (≤4096) /
Высокий (≤16000). По умолчанию выключено: для обычного брейншторма
редко даёт пользу, а счёт может незаметно вырасти. Не все модели это
поддерживают — там настройка просто не даёт эффекта.

## Ведущий

Вместо строгой очереди порядок реплик определяет ведущий — а также что
участнику делать, зачем, и не пора ли подводить итог.

- **ИИ-ведущий** (по умолчанию) — отдельный, обычно дешёвый, вызов
  модели после каждой реплики. Скрыт из самого чата.
- **Человек-ведущий** — вы сами выбираете каждого оратора, без
  дополнительных затрат API. Та же панель позволяет оставить
  комментарий или сразу завершить сессию.

**Участие** — если включено, ведущий может время от времени передавать
слово и вам (ограничено так, что это не может случиться два раза
подряд — предвзятый ведущий не сможет застопорить сессию на вас
бесконечно). Ваши реплики не считаются в лимите реплик и бюджете.

**Итог сессии** — необязательный дополнительный вызов после окончания
сессии, просит модель ведущего дать тезисный пересказ: ключевые идеи,
точки согласия/разногласий, общий вывод.

**Вмешательство** — поставить обсуждение на паузу, оставить уточнение
для участников, или сразу завершить сессию. Отдельная кнопка в режиме
ИИ-ведущего; встроено в панель выбора оратора в режиме человека.

Самая последняя реплика сессии всегда направляется к подведению итога,
независимо от того, вспомнил ли об этом сам ведущий.

## Бюджет и длина

Два независимых стоп-фактора — что наступит раньше:

- **Бюджет** ($, задаётся в настройках) — включает и реплики
  участников, и вызовы ведущего. OpenRouter возвращает точную стоимость
  каждого запроса; она показана под каждой репликой (курсивом, серым,
  по правому краю), с разбивкой, если туда же попадает стоимость
  вызова ведущего (например, «$0.0031 + ведущий $0.0012 = $0.0043»).
- **Макс. реплик** (задаётся на вкладке «Чат») — считает только реплики
  участников, не вызовы самого ведущего и не ваши реплики.

Модель, начавшая отдавать ошибки (лимиты запросов и т.п.), уходит на
короткое «охлаждение» и исключается из вариантов выбора ведущего —
тихо, без спама в чат; причина остаётся видна во вкладке «Лог».

## Отображение чата

- `**жирный**`, `` `инлайн-код` ``, блоки ` ```кода``` `, заголовки и
  маркированные списки рендерятся по-настоящему, а не сырым markdown-текстом.
- Реплики визуально разделены линией.
- Собственные заметки (тема, комментарии, реплики) выделены отдельным
  цветом; итог сессии — своим акцентным цветом.
- **Ctrl+C** копирует выделенное, **Ctrl+A** выделяет всё, «Копировать
  всё» — весь лог одним кликом.
- **Экспорт…** сохраняет в `.md` или `.txt`, собирается из исходного
  текста реплик (со всей markdown-разметкой как есть), а не из того,
  что отрисовано на экране.

## Вкладка «Лог»

Необязательная вкладка, дублирующая то, что показала бы консоль —
вызовы моделей, стоимость, решения ведущего, ошибки. Включается на
вкладке «Настройки»; хранит свою историю всю сессию приложения, даже
пока скрыта. Копируется и выделяется так же, как лог чата.

## Структура проекта

```
ai_brainstorm/
├── main.py             — точка входа, интерфейс на Tkinter, логика ведущего/воркера
├── config.py            — профили, общеприложенческие настройки, пути к папке языков
├── models_catalog.py    — семейства моделей, уровни рассуждений, сборка каталога
├── api_client.py        — вызовы OpenRouter: чат, ведущий, список моделей, баланс ключа
├── i18n.py               — загрузка/fallback переводов, встроенные RU/EN словари
├── theme.py               — палитры Светлая/Тёмная, тема для ttk.Style() и обычных Text/Canvas
├── favicon.ico           — иконка приложения (необязательно, добавьте свою)
├── README.md / README.ru.md
```
